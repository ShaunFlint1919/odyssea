# Nova Corsair

Shoot'em up spatial original à défilement vertical, nerveux, multi-planètes, avec boutique
d'amélioration entre les missions — pour Android (APK) et navigateur.

- Code du jeu : [`game/`](game/) — voir [`game/README.md`](game/README.md) (lancer, tester, installer l'APK, publier)
- Méga-prompt de la boucle de développement : [`game/docs/MEGA_PROMPT.md`](game/docs/MEGA_PROMPT.md)
- Feuille de route : [`game/docs/ROADMAP.md`](game/docs/ROADMAP.md) · Journal : [`game/docs/PROGRESS.md`](game/docs/PROGRESS.md)
- APK de test : onglet **Actions** → workflow **Android APK** → dernier run vert → **Artifacts**
  (`nova-corsair-…-debug.apk` direct, ou le zip `nova-corsair-debug-apk`).
- Versions publiées (tags `v*`) : page **Releases** (APK signée, bundle `.aab` pour Google Play).

---

Original fast-paced vertical scrolling space shooter with a multi-planet campaign and an upgrade
shop between missions — Android (Capacitor) + web (Phaser 3 + TypeScript + Vite). Test APKs: **Actions**
→ **Android APK** → latest green run → **Artifacts**; tagged versions: **Releases**. Details in
[`game/README.md`](game/README.md).
